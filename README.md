# QRcodepusher

<img src="logo.png" width="320" height="240" alt="logo">

このプロジェクトは、QRコードを利用してエアギャップ環境でもデータのやり取りが可能かどうかを調査するためのプロジェクトです。

## 使用方法

### ファイルを送信する
```bash
python3 -s -n file
```

### ファイルを受信する
```bash
python3 -r -n file
```

※ ファイル名を指定しない場合は、`data` というファイルが作成されます。
